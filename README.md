# Lifeguard Scheduling & Analytics Tool

This is a Python project I am building to analyze lifeguard staffing data and improve scheduling decisions.

Current functionality:
- Collects guard names and hours worked
- Outputs a simple daily summary
- Calculates total hours

Planned improvements:
- Analyze coverage gaps
- Add scheduling optimization logic
- Expand data handling and automation

This project is based on real operational data from my role as a Lifeguard Manager.
